# SmartAttend

SmartAttend is a Django-based smart college attendance management system designed to simplify attendance management for students, faculty, and administrators.

## 🚀 Features

- Student login
- Faculty login
- Admin panel
- Role-based authentication
- Department management
- Class and section management
- Subject management
- Faculty teaching assignments
- OTP-based attendance
- Attendance session management
- Student attendance marking
- Attendance history
- Demo accounts for testing
- CSV-based subject data import

## 🛠️ Tech Stack

- Python
- Django
- Django REST Framework
- SQLite
- HTML
- CSS
- JavaScript
